大学生职业网 CampusCareer V3.1 使用说明
==========================================

一、启动
------------------------------------------
1. 双击 start.bat（或在本目录执行 python server.py --host 0.0.0.0 --port 8080）
2. 浏览器会自动打开登录页；若没有自动打开，手动访问：
   本机：    http://127.0.0.1:8080
   局域网：  http://<本机IP>:8080   （同一 Wi-Fi 下的其它电脑/手机）

二、登录账号
------------------------------------------
默认管理员账号：admin
默认密码：JhYMaOkJI_pI

访客自助注册：
- 打开 http://127.0.0.1:8080/register 可自行注册学生账号，注册成功自动登录。
- 账号规则：3-20 位字母、数字或下划线；密码至少 8 位，需同时含字母和数字。

提示：
- 密码以 PBKDF2-HMAC-SHA256 加盐哈希存储在 career.db 的 users 表，不保存明文。
- 若删除了 career.db，服务首次启动会重新生成数据，会在控制台日志中打印
  「首次启动已创建管理员账号：admin  密码：xxxx」，请以日志中的密码为准。
- 也可用环境变量 ADMIN_PASSWORD 指定首次启动的管理员密码。
- 退出登录：页面右上角「退出」按钮。

三、让其它电脑访问（局域网）
------------------------------------------
1. 确认服务以 0.0.0.0 监听（start.bat 默认如此）。
2. 查询本机 IP：在命令行执行 ipconfig，找到「IPv4 地址」，例如 192.168.1.102。
3. 其它电脑在同一局域网内打开 http://192.168.1.102:8080 即可。
4. 如果其它电脑打不开，多半是 Windows 防火墙拦截：
   双击 allow_firewall.bat（会弹出管理员授权），自动添加 TCP 8080 入站规则。

四、让外网电脑访问（公网）
------------------------------------------
方案 A：Render 托管（推荐，可拿到固定 https 域名）
   详见同目录 DEPLOY_RENDER.txt，几分钟即可上线，地址形如
       https://campus-career-xxxx.onrender.com
方案 B：内网穿透（无需公网 IP，最省事，但地址每次重启会变）
   1. 安装 cloudflared，执行：
        cloudflared tunnel --url http://127.0.0.1:8080
      命令会给出一个 https://xxx.trycloudflare.com 地址，任何电脑/手机都能打开。
   2. 建议同时设置环境变量 CC_HTTPS_REDIRECT=1 再启动服务，
      让 http 访问自动跳转 https，并给登录 Cookie 加上 Secure 标记。
方案 C：云服务器
   1. 把整个目录上传到服务器，执行
        python server.py --host 0.0.0.0 --port 8080
   2. 用 nginx 反向代理并配置证书（443 -> 8080），启动服务时设置 CC_HTTPS_REDIRECT=1。
   3. 安全组/防火墙放行对应端口。

五、安全说明
------------------------------------------
- 除登录页与注册页外，所有页面与接口都要求登录：未登录访问页面会跳转 /login，访问接口返回 401。
- 登录会话为 HMAC 签名的 HttpOnly Cookie，默认 12 小时有效；篡改或过期即失效。
- 同一 IP 在 60 秒内连续输错密码 8 次会被锁定并返回 429；注册接口同样有限流。
- 注册接口只允许创建 student 角色账号，管理员账号只能由服务端初始化产生。
- 站点内含姓名/手机号/邮箱等演示数据，公网开放前请评估风险。

六、环境变量
------------------------------------------
PORT              监听端口，默认 8080（云平台通常自动注入）
CC_HOST           监听地址，默认 0.0.0.0
CC_SECRET_KEY     会话签名密钥，至少 32 位；设置后实例重启不掉登录
ADMIN_PASSWORD    首次启动时 admin 账号的密码
CC_DB_PATH        数据库文件路径，默认当前目录 career.db
CC_HTTPS_REDIRECT 设为 1 时把 http 请求 301 跳到 https

七、目录结构
------------------------------------------
server.py       HTTP 服务与路由（零第三方依赖，仅用 Python 标准库）
auth.py         账号、密码哈希、会话签名、登录限流、注册校验
db.py           SQLite 建表与连接
seed.py         幂等灌库 + 首次创建管理员账号
seed_data.py    演示数据（企业 22、岗位 70、面试题 22、薪资 26、测评题 18）
career.db       数据库文件（含 users 表）
templates/      8 个功能页面 + 登录页 + 注册页
static/         样式、脚本、截图
start.bat       启动脚本（自动识别本机 IP）
allow_firewall.bat  防火墙放行脚本（需管理员授权）
render.yaml     Render 一键部署配置
DEPLOY_RENDER.txt   公网部署详细步骤
